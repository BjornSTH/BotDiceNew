# BotDice

Telegram-бот для бросков кубиков в D&D, написан на Go.

## Установка на сервер

```sh
git clone https://github.com/BjornSTH/BotDiceNew.git
cd BotDiceNew
./setup.sh
```

Скрипт соберёт бота, спросит токен (ввод скрыт) и запустит его как systemd-сервис
с автозапуском. Токен в репозитории и коде не хранится.

```sh
./setup.sh token       # заменить токен
./setup.sh uninstall   # удалить
journalctl -u botdice -f
```

Для сборки нужен Go 1.26+. Без systemd бота можно запустить вручную: `go build -o botdice . && ./botdice`.

## Команды

| Сообщение | Что делает |
|---|---|
| `к20`, `d20`, `3к6` | бросок кубов |
| `к20+5`, `2к6+1к4+3` | с модификаторами и суммой |
| `пр к20+5` / `пм к20+5` | преимущество / помеха |
| `/help` | справка |

В одном сообщении можно несколько бросков, каждый с новой строки или через пробел.
